About the project

A small agency can’t build a new webshop for every client, so with our developers we built one CMS for all of them.

These four brands look nothing alike, yet they run on the same system. For each one I only changed the UI and variables in Figma, and added components where needed.

The system

The CMS grew with each project, the Figma system grew with it, and a new brand came down to a few choices: webshop or not, blog or news, which filters, which component variant.

The payoff

Four very different brands, one checkout and one CMS behind them. Building it taught me more about working with developers than any project before.

What I took from it

  • Tokens are a contract. Keeping them one to one with the developer turned every handover into a single list of changes.
  • Write the spec yourself. It’s the fastest way to learn how a developer thinks, and what a handover really needs.
  • A good system buys time. With nothing to rebuild, there was room to sit with stakeholders and get the brief right.

Faster with every project

By the end, client conversations took more time than Figma.
